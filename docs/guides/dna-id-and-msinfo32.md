# DNA ID and msinfo32

Your **DNA ID** is your card's unique number. MewTools reads it on the SECOND PC (the one the card plugs into). See [Getting your DNA ID](getting-your-dna-id.md).

**msinfo32** is a system report from Windows. It is only needed if your firmware provider asks for it. MewDMA does, so MewDMA customers send an msinfo32 file from the **MAIN PC** (the gaming PC) along with their DNA ID. If your provider does not ask for it, you can skip this.

## Saving msinfo32

Do this on the MAIN PC, not the second PC.

1. Press **Windows key + R**, type **msinfo32**, press Enter.
2. In the System Information window, click **File**, then **Save** (or **Export**).
3. Save it somewhere easy to find, like your Desktop. The default **.nfo** is fine; Export makes a **.txt**. Either works.
4. Upload that file to the same order as your DNA ID at mewdma.net.

## Tips
- It has to come from the MAIN PC. The report from the second PC is not what we need.
- Save it while your usual hardware is plugged in and running normally.
- No personal files are in it. It is a hardware and driver report.

# DNA ID and msinfo32

Your **DNA ID** is your card's unique number, and MewTools reads it on the SECOND PC (the one the card plugs into). See [Getting your DNA ID](getting-your-dna-id.md).

**msinfo32** is a Windows system report, and you only need it if your firmware provider asks for it. We do, so MewDMA customers send an msinfo32 file from the **MAIN PC** (the gaming PC) along with their DNA ID. If your provider doesn't ask, skip it.

## Saving msinfo32

Do this on the MAIN PC, not the second PC.

1. Press **Windows key + R**, type **msinfo32** and press Enter.
2. In the System Information window, click **File**, then **Save** (or **Export**).
3. Save it somewhere easy like your Desktop. The default **.nfo** is fine, and Export makes a **.txt**. Either works.
4. Upload that file to the same order as your DNA ID at mewdma.net.

## Tips
- It has to come from the MAIN PC, because the second PC's report isn't what we need.
- Save it while your usual hardware is plugged in and running normally.
- There are no personal files in it, just a hardware and driver report.

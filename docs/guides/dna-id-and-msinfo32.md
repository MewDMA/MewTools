# DNA ID and msinfo32

Your **DNA ID** is your card's own unique number. MewTools reads it on the SECOND PC (the one the card plugs into). See [Getting your DNA ID](getting-your-dna-id.md).

**msinfo32** is a Windows system report, and you only need it if your firmware provider asks for it. We do ask, so MewDMA customers send an msinfo32 file from the **MAIN PC** (the gaming PC) along with their DNA ID. If your provider doesn't ask, just skip it.

## Saving msinfo32

Do this on the MAIN PC, not the SECOND PC.

1. Press **Windows key + R**, type **msinfo32** and press Enter.
2. In the System Information window, click **File**, then **Save** (or **Export**).
3. Save it somewhere easy like your Desktop. The default **.nfo** is fine and Export makes a **.txt**, so either works.
4. Upload that file at mewdma.net to the same order as your DNA ID.

## Tips
- It has to come from the MAIN PC, because the SECOND PC's report isn't what we need.
- Save it while your usual hardware is plugged in and running normally.
- There are no personal files in it. It's just a hardware and driver report.
